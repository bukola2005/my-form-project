# Sign-Up Form

This is a modern, responsive sign-up form project built with HTML and SCSS. 
It features a mobile-first responsive design, modern UI elements, and glassmorphism effects.

## Features

- Responsive layout that adapts from mobile to desktop
- Modern "Untitled UI" navigation bar
- Hover and interaction animations on buttons and menu items
- Glassmorphism effect tags on the sidebar
- Form validation

## Getting Started

1. Clone or download the repository.
2. Open `index.html` in your web browser.
3. If you want to modify styles, make your changes in `assets/scss/style.scss` and compile it to `assets/css/style.css` using your preferred SCSS compiler (e.g., the `sass` CLI or a VS Code extension).

## Design Highlights

- **Mobile Menu**: The hamburger menu features a clean, borderless design with a smooth hover rotation animation.
- **Glassmorphism**: The sidebar uses modern CSS blur filters to create a frosted glass effect on the tags.
- **Form Validation**: Clean visual cues for valid and invalid inputs using native CSS pseudo-classes.
